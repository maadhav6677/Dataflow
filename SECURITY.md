# Security and data boundary

This repository is intentionally local-first and dependency-free.

- Every business record is generated by `src/generate_data.py`; there is no scraped, customer, employee, or confidential Hyperpure data.
- The pipeline makes no network calls and needs no credentials, secrets, or environment variables.
- CSV headers and value domains are validated before load. SQLite foreign keys and `CHECK` constraints enforce relationships and ranges.
- The warehouse is built at a temporary path and atomically replaced only after validation succeeds.
- The dashboard uses no third-party scripts, trackers, forms, cookies, or outbound requests.
- CI has read-only repository permissions.

Report a security concern privately to the repository owner rather than opening a public issue containing sensitive information.
